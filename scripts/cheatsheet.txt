BEHAVIOUR STAT PIPELINE - CHEATSHEET  (PowerShell, run from the repo root)
Full explanation of every step: docs/pipeline_guide.md

=====================================================================
0. SET THE EXPERIMENT ONCE PER TERMINAL
=====================================================================

$exp = "configs/experiments/EXP-2026-002.yaml"
$cfg = "configs/stats.yaml"

(All commands below use $exp and $cfg. For another experiment, change $exp.)


=====================================================================
1. INGEST: raw tracking files -> data/experiments/<EXP>/processed/<ASSAY>_processed.csv
=====================================================================

python scripts/run_assay.py --assay vit  --config $cfg --experiment-config $exp
python scripts/run_assay.py --assay nor  --config $cfg --experiment-config $exp
python scripts/run_assay.py --assay lm   --config $cfg --experiment-config $exp
python scripts/run_assay.py --assay oft1 --config $cfg --experiment-config $exp
python scripts/run_assay.py --assay oft2 --config $cfg --experiment-config $exp
python scripts/run_assay.py --assay oft3 --config $cfg --experiment-config $exp
python scripts/run_assay.py --assay oft4 --config $cfg --experiment-config $exp
python scripts/run_assay.py --assay misc --config $cfg --experiment-config $exp
(EXP-2025-001 also has: --assay epm, --assay oft)


=====================================================================
2. STATS: processed data -> outputs/<EXP>/<ASSAY>/tables/
=====================================================================

All assays in the experiment's plan (analysis.assays in $exp), incl. linear/mixed models:
    python scripts/run_stats.py --config $cfg --experiment-config $exp

Selected assays only:
    python scripts/run_stats.py --config $cfg --experiment-config $exp --assays nor lm

Mixed models that stack sessions (OFT2-4 with OFT1 baseline) only run when all
their assays are in the same run:
    python scripts/run_stats.py --config $cfg --experiment-config $exp --assays oft1 oft2 oft3 oft4

FOR RESULTS YOU WILL REPORT: commit first, then add --require-clean
(refuses uncommitted changes and a changed frozen plan; every table then traces to a commit):
    python scripts/run_stats.py --config $cfg --experiment-config $exp --require-clean


=====================================================================
3. FIGURES: -> outputs/<EXP>/<ASSAY>/figures/   (run stats first: figures read the tables)
=====================================================================

python scripts/run_figures.py --config $cfg --experiment-config $exp --assays nor lm oft1 oft2 oft3 oft4 vit misc
python scripts/run_figures.py --config $cfg --figures-config configs/figures.yaml --experiment-config $exp --assays oft2


=====================================================================
4. EXTRA ANALYSES / CHECKS
=====================================================================

Heteroscedasticity across all processed files:
    python scripts/combine_processed_and_check_heteroscedasticity.py --experiment-config $exp

NOR individual trajectories:
    python scripts/nor_check_individual_change.py --experiment-config $exp


=====================================================================
5. WHERE THINGS LIVE
=====================================================================

configs/stats.yaml                 method defaults (corrections, ANOVA type, thresholds) - shared
configs/experiments/<EXP>.yaml     paths, assay instances (order, day, trial_duration_s), exclusions file,
                                   and the ANALYSIS PLAN (analysis: endpoints, models, primary_endpoints)
configs/figures.yaml               figure styling and manual figure specs
configs/labels.csv                 axis labels / titles per endpoint
data/experiments/<EXP>/metadata/   subjects.csv, exclusions.csv
outputs/<EXP>/<ASSAY>/tables/      result tables (every table has run_id and endpoint_role)
outputs/<EXP>/<ASSAY>/logs/        <ASSAY>_provenance.json (commit, input hashes, versions), summaries
outputs/<EXP>/MODELS/              linear / mixed model results
docs/changelog.md                  every change that affects results


=====================================================================
6. ANALYSIS PLAN (in $exp, under analysis:)
=====================================================================

Declare primary endpoints (everything else = exploratory, corrected separately):
    analysis:
      primary_endpoints:
        nor: [di_explore]
        oft_post_sessions: [total_distance_moved]     # linear model name

Order of tests (needed for stacked sessions / baselines; never inferred from names):
    assay_instances:
      OFT1: {order: 1, day: -3}    # day optional, e.g. days relative to IFS onset

Freeze the plan before analysing:
    git add $exp ; git commit -m "Freeze analysis plan EXP-2026-002"
    git rev-parse HEAD                 -> copy the sha
    add to $exp (top level):  analysis_frozen_at: <sha>


=====================================================================
7. TESTS
=====================================================================

All tests (R-dependent ones are skipped if R is not installed):
    python -m pytest

Only the statistics validated against R:
    python -m pytest tests/reference

Regenerate the R reference values (only if the fixture or the R script changed):
    python tests/reference/generate_fixture.py
    & "C:\Program Files\R\R-4.5.0\bin\Rscript.exe" tests/reference/generate_reference.R

=====================================================================
9. REVIEW BUNDLE AND TINY TEST DATA
=====================================================================

Review folder and ZIP:
    powershell -ExecutionPolicy Bypass -File .\scripts\update_review_bundle.ps1 -experiment EXP-2026-002

Stable 4-ID sample:
    python scripts/update_tiny_test_data.py --experiment EXP-2026-002 --n 4 --seed 42 --fresh
Fresh random sample:
    python scripts/update_tiny_test_data.py --experiment EXP-2026-002 --n 4 --seed (Get-Random) --fresh


=====================================================================
10. POWERSHELL / GIT SNIPPETS
=====================================================================

Create files/folders:
    New-Item -ItemType Directory -Path src\behaviour_stat_pipeline\figures -Force | Out-Null
    New-Item -ItemType File -Path src/behaviour_stat_pipeline/common/exclusions.py

Delete outputs (locally too):
    del .\outputs\EXP-2026-002\LM\figures\LM_*.png

Find a string/function across files:
    Get-ChildItem -Recurse -Filter *.py | Select-String "group_gap"

Stop tracking files already added (.gitignore does not untrack files Git already knows;
this removes them from the index without deleting them locally):
    git rm -r --cached outputs
    git rm -r --cached data/processed

All column names of a processed CSV (header only):
    Get-ChildItem data\experiments\EXP-2026-002\processed\LM_processed.csv | ForEach-Object { Import-Csv $_ | Get-Member -MemberType NoteProperty | Select-Object -ExpandProperty Name } | Sort-Object -Unique
    Get-ChildItem data\experiments\EXP-2026-002\raw\nor\27a_FAM_output_summary.csv | ForEach-Object { Import-Csv $_ | Get-Member -MemberType NoteProperty | Select-Object -ExpandProperty Name } | Sort-Object -Unique
