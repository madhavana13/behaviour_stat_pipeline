# Behavioral Diagnostics Table — Reading Cheatsheet

This document explains how to interpret the diagnostics tables generated by the analysis pipeline.  
It is intended as a quick reference during QC, analysis decisions, and reporting.

---

## 1. Basic usability checks

These columns answer the question: *Is this endpoint usable at all?*

| Column | Meaning | Guideline |
|------|--------|----------|
| `status` | Pipeline QC status | Should be `ok`. Any other value requires inspection |
| `n_total` | Total animals | Should match expected cohort size |
| `n_nonmissing` | Rows with valid data | Prefer ≥80% of `n_total` |
| `missing_frac` | Fraction missing | 0 ideal; >0.2 requires caution |

Decision:
- High missingness (>30%) compromises interpretability.
- Zero missingness does not guarantee quality, but is a good sign.

---

## 2. Central tendency and spread

These describe the distribution shape and variability.

| Column | Meaning | How to interpret |
|------|--------|----------------|
| `mean` | Arithmetic average | Sensitive to outliers |
| `median` | Robust center | Compare to mean for skew |
| `sd` | Standard deviation | Absolute variability |
| `cv` | Coefficient of variation | Relative variability (sd / mean) |
| `iqr` | Interquartile range | Middle 50% spread |
| `mad` | Median absolute deviation | Robust alternative to SD |

Rules of thumb:
- Mean ≈ median suggests symmetry.
- Large SD is not inherently bad; interpret in context.
- CV > 1 is common for ratios and indices.

---

## 3. Range and outliers

| Column | Meaning | What to check |
|------|--------|--------------|
| `min` | Minimum value | Near-zero may indicate floor effects |
| `max` | Maximum value | Check biological plausibility |
| `mad_z_thresh` | Outlier threshold | Typical values: 3–3.5 |

Notes:
- Outliers should not be removed automatically.
- Removal requires biological or technical justification.

---

## 4. Variance diagnostics (assumptions)

These determine whether standard parametric tests are appropriate.

### Brown–Forsythe test
| Column | Meaning | Interpretation |
|------|--------|---------------|
| `brown_forsythe_p` | Test of equal variances | p < 0.05 suggests unequal variances |
| `hetero_flag` | Convenience flag | True indicates heteroscedasticity |

Important:
- Heteroscedasticity is common in behavioral data.
- It is not a reason to discard an endpoint.

---

### Variance ratio

| `var_ratio` value | Interpretation |
|------------------|----------------|
| ~1–2 | Excellent |
| 2–4 | Acceptable |
| >4 | Use caution |
| >10 | Serious concern |

Balanced group sizes reduce the impact of moderate variance differences.

---

## 5. Sample size constraints

| Column | Meaning | Rule |
|------|--------|-----|
| `min_n_test` | Minimum n per group | Absolute minimum: 3 |
| `grouping` | Analysis unit | Confirms factor used |

Endpoints with fewer than 3 animals per group should not be tested inferentially.

---

## 6. Decision guide for statistics

Use this table to decide analysis strategy.

| Situation | Recommended approach |
|---------|---------------------|
| No heteroscedasticity, balanced n | Standard ANOVA |
| Mild heteroscedasticity | Welch ANOVA or robust methods |
| Unequal variances + small n | Permutation or rank-based tests |
| Severe variance or floor effects | Treat as exploratory or exclude |

---

## 7. Endpoint-specific expectations

Different measures naturally behave differently.

| Endpoint type | Typical behavior |
|--------------|------------------|
| Exploration time | Mild variance heterogeneity |
| Locomotion | Group-dependent variance |
| Discrimination indices | High CV, skewed |
| Interaction zone metrics | More stable distributions |
| Ratios | Outliers and skew common |

Deviations from these expectations warrant closer inspection.

---

## 8. Reporting template

Suggested sentence for methods or figure legends:

> Data quality was assessed using missingness, robust dispersion metrics, and variance diagnostics. Where variance heterogeneity was detected, variance-robust statistical methods were applied.

---

## 9. Summary principle

Diagnostics inform *how* to analyze data, not whether the data are “good” or “bad”.  
Most behavioral datasets require robust statistics rather than exclusion.
